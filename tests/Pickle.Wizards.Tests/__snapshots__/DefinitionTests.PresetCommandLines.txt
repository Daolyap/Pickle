## 7z
Zip a folder:
  7z a -tzip backup.zip folder
Ultra-compressed 7z:
  7z a -mx=9 archive.7z folder
Split into 100 MB parts:
  7z a -v100m big.7z videos
Zip without temp files:
  7z a -tzip '-xr!*.tmp' '-xr!*.log' project.zip project
Extract to a folder:
  7z x -oout -aoa archive.7z
List contents:
  7z l archive.7z
Test archive:
  7z t archive.zip

## adb

## curl
GET JSON:
  curl -H 'Accept: application/json' -s -S -f https://api.github.com/repos/PowerShell/PowerShell
POST JSON:
  curl --json '{"name":"pickle","crunchy":true}' https://httpbin.org/post
Download file:
  curl -o powershell-master.zip -f -L https://github.com/PowerShell/PowerShell/archive/refs/heads/master.zip
Headers only:
  curl -I -L https://example.com
Upload a file (form):
  curl -F file=@report.pdf -F 'comment=Quarterly report' https://httpbin.org/post
Retry a flaky endpoint:
  curl -s -S -f --retry 5 --retry-delay 2 https://example.com/health
Status code and timing:
  curl -o response.html -s -w '%{http_code} %{time_total}s\n' https://example.com

## ffmpeg
Convert to MP4 (H.264/AAC):
  ffmpeg -i input.mkv -c:v libx264 -crf 23 -pix_fmt yuv420p -c:a aac -b:a 192k -movflags +faststart output.mp4
Extract audio as MP3:
  ffmpeg -i video.mp4 -vn -c:a libmp3lame -b:a 192k audio.mp3
Trim without re-encoding:
  ffmpeg -ss 00:01:00 -i input.mp4 -t 00:00:30 -c copy clip.mp4
Resize to 720p:
  ffmpeg -i input.mp4 -c:v libx264 -crf 23 -vf scale=-2:720 -c:a copy output-720p.mp4
Compress with H.265:
  ffmpeg -i input.mp4 -c:v libx265 -crf 28 -preset slow -c:a aac -b:a 128k output-hevc.mp4
Make a GIF:
  ffmpeg -i input.mp4 -vf 'fps=10,scale=480:-1:flags=lanczos' output.gif
Remux MKV to MP4:
  ffmpeg -y -i input.mkv -c copy output.mp4

Windows Update client:
  Get-WinEvent -FilterHashtable @{LogName='System'; ProviderName='Microsoft-Windows-WindowsUpdateClient'} -MaxEvents 20
Latest Application events:
  Get-WinEvent -LogName Application -MaxEvents 20
PowerShell operational log:
  Get-WinEvent -LogName Microsoft-Windows-PowerShell/Operational -MaxEvents 50
Logs with events:
  Get-WinEvent -ListLog '*'
Read a saved log:
  Get-WinEvent -Path C:\Logs\saved.evtx -MaxEvents 100

## git
Commit all tracked changes:
  git commit -m 'Fix typo in README' -a
Commit with subject and body:
  git commit -m 'Add login page' -m 'Includes form validation and tests.'
Amend, keep message:
  git commit --amend --no-edit
  ! Amend the last commit: Rewrites the last commit; don't amend commits that were already pushed.
New branch from origin/main:
  git switch -c feature/login origin/main
Delete merged branch:
  git branch -d feature/old
Branches with upstream info:
  git branch -a -vv
Interactive rebase (last 5):
  git rebase -i --autosquash HEAD~5
Continue rebase:
  git rebase --continue
Stash including untracked:
  git stash push -m 'wip: experiments' -u
Pop latest stash:
  git stash pop
Apply a specific stash:
  git stash apply 'stash@{1}'
Graph of all branches:
  git log --oneline --graph --decorate --all -n 30
History of a file:
  git log -p --follow -- src/Program.cs
My commits this week:
  git log '--format=%h %ad %s' --author me@example.com --since '1 week ago'
Undo last commit, keep changes:
  git reset --soft HEAD~1
Discard all local changes:
  git reset --hard HEAD
  ! Mode hard (discard everything): Permanently discards uncommitted changes to tracked files.
Shallow clone:
  git clone --depth 1 https://github.com/PowerShell/PowerShell.git
Partial clone:
  git clone --filter=blob:none https://github.com/PowerShell/PowerShell.git pwsh
Log in another folder:
  git -C C:\src\project log --oneline -n 10

## netsh
Forward port 8080:
  netsh interface portproxy add v4tov4 listenport=8080 listenaddress=0.0.0.0 connectport=80 connectaddress=192.168.1.10
Show port proxies:
  netsh interface portproxy show all
Remove port proxy:
  netsh interface portproxy delete v4tov4 listenport=8080 listenaddress=0.0.0.0
Allow inbound TCP 8080:
  netsh advfirewall firewall add rule 'name=Dev server 8080' dir=in action=allow protocol=tcp localport=8080 profile=private
Show a firewall rule:
  netsh advfirewall firewall show rule 'name=Dev server 8080' verbose
Delete a firewall rule:
  netsh advfirewall firewall delete rule 'name=Dev server 8080'
  ! Name: Deletes every rule with this name.
Saved Wi-Fi networks:
  netsh wlan show profiles
Wi-Fi password:
  netsh wlan show profiles name=HomeWiFi key=clear
IP configuration:
  netsh interface ip show config

## openssl
Self-signed cert for localhost:
  openssl req -x509 -newkey rsa:4096 -keyout key.pem -nodes -subj /CN=localhost -addext 'subjectAltName=DNS:localhost,IP:127.0.0.1' -days 365 -sha256 -out cert.pem
CSR with a new key:
  openssl req -new -newkey rsa:2048 -keyout server.key -nodes -subj '/C=US/O=Example Inc/CN=www.example.com' -out server.csr
PEM to PFX:
  openssl pkcs12 -export -in cert.pem -inkey key.pem -name 'My certificate' -out cert.pfx
PFX to PEM (unencrypted key):
  openssl pkcs12 -in cert.pfx -out cert.pem -nodes
Inspect certificate:
  openssl x509 -in cert.pem -text -noout
Expiry dates:
  openssl x509 -in cert.pem -subject -dates -noout
SHA-256 fingerprint of a .cer:
  openssl x509 -in cert.cer -inform DER -fingerprint -sha256 -noout
EC P-256 key:
  openssl genpkey -algorithm EC -pkeyopt ec_paramgen_curve:P-256 -out ec.key
RSA 4096 key:
  openssl genpkey -algorithm RSA -pkeyopt rsa_keygen_bits:4096 -out rsa.key
SHA-256 of a file:
  openssl dgst -sha256 download.iso
Check a server certificate:
  openssl s_client -connect example.com:443 -servername example.com -brief

## robocopy
Mirror a folder:
  robocopy C:\Source D:\Backup\Source /MIR /MT:16 /R:2 /W:5
  ! Mirror: Deletes files and folders in the destination that don't exist in the source.
Mirror dry run:
  robocopy C:\Source D:\Backup\Source /MIR /L
  ! Mirror: Deletes files and folders in the destination that don't exist in the source.
Copy everything:
  robocopy C:\Source D:\Copy /E /Z /R:3 /W:5
Copy only documents:
  robocopy C:\Users\me\Documents E:\Docs '*.docx' '*.xlsx' '*.pdf' /S /XO
Backup with a log:
  robocopy C:\Data \\nas\backup\data /E /Z /LOG:C:\Logs\backup.log /TEE /NP
Skip build folders:
  robocopy C:\src\app D:\app-copy /E /XF '*.tmp' /XD node_modules /XD .git /XD bin /XD obj
Move old logs:
  robocopy C:\App\logs D:\Archive\logs '*.log' /MOV /MINAGE:30
  ! Move files: Deletes the source files after they are copied.

## rsync
Deploy a folder over SSH:
  rsync -a -z -v ./site/ user@example.com:/var/www/site/
Mirror (delete extras):
  rsync -a --delete src/ backup/
  ! Delete extraneous files: Deletes files in the destination that don't exist in the source. Try a dry run (-n) first.
Dry run of a mirror:
  rsync -a -v -n --delete src/ backup/
  ! Delete extraneous files: Deletes files in the destination that don't exist in the source. Try a dry run (-n) first.
SSH on a custom port:
  rsync -a -e 'ssh -p 2222' data/ user@example.com:data/
Resumable large copy:
  rsync -a -P videos/ /mnt/nas/videos/
Skip build output:
  rsync -a --exclude=node_modules --exclude=.git '--exclude=*.log' project/ user@example.com:project/

  ssh -L 0.0.0.0:8080:localhost:80 -N user@example.com

## yt-dlp
Best quality as MP4:
  yt-dlp -f 'bv*+ba/b' --merge-output-format mp4 'https://www.youtube.com/watch?v=VIDEO_ID'
Audio as MP3:
  yt-dlp -x --audio-format mp3 --audio-quality 0 'https://www.youtube.com/watch?v=VIDEO_ID'
At most 1080p:
  yt-dlp -S res:1080 'https://www.youtube.com/watch?v=VIDEO_ID'
Numbered playlist:
  yt-dlp -o '%(playlist_index)03d - %(title)s.%(ext)s' --yes-playlist 'https://www.youtube.com/playlist?list=PLAYLIST_ID'
With English subtitles:
  yt-dlp --write-subs --sub-langs 'en.*' --embed-subs 'https://www.youtube.com/watch?v=VIDEO_ID'
List formats:
  yt-dlp -F 'https://www.youtube.com/watch?v=VIDEO_ID'
